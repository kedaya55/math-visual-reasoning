# 连续动画制作

数学论证确定后、编写动画前读取。以数学对象及其状态为制作单位；一条推理链可以持续处于同一个场景。

## 对象与依据

在 `STORYBOARD.md` 为需要追踪的对象记录：语义 ID、数学含义、参数来源、颜色与标签、建立/分割/退出时机。分割记录父对象及覆盖关系；高亮或符号副本不表示新增面积。

凡是理解转化所需的对应关系，都应在分割、移动或重组开始前，用标签、描边或区域高亮等必要标记说明来源，并留出识别时间。标记随同一对象延续，分割后的相关部分继承原有标记，让学生沿变化看清来源与去向，而不必在落定后回忆、猜测。只标记当前推理需要的关系；结果名称或公式可以在对应关系建立后出现。

边长绑定物理边，点名绑定点，数值绑定参数，描边或高亮绑定所指的边、弧或区域。若标记需要交接到新位置或表达，先用对齐、高亮或引线说明对应，再让旧标记退出。

旋转边长标注时，锚点与外法线跟随边旋转，文字保持正立；不要按屏幕“上边/左边”重判身份。具体实现按需使用 [边长标注组件](edge-label.md)。提前给图形、括号和文字一起规划运动空间；碰撞时调整路径或布局，不能隐藏推理必需的标签。

## 复杂转化的追踪设计

当相似对象较多、运动路径交叉或多个对象同时分割与重排，使来源与去向难以辨认时，主动增加视觉区分并调整动作组织。是否需要处理取决于对应关系能否看清，不按元素数量机械加色。

- 用少量颜色、区域填色或描边区分需要追踪的来源组，并在转化前建立含义。同一来源的子块继承该组标记；只有需要辨认子块彼此时才增加组内差异。避免每块任意换色，也不覆盖已有变量、边长或边界的颜色含义；保留线型、位置或标签等辅助线索。
- 若仍难追踪，先突出一个代表对象或一组关系，讲清分割与对应，再推广到其余对象；按依赖关系分批、错开或分步运动，必要时拉开空间。分割、辨认、重排之间留出观察时间，不让新结构刚出现就与其他变化同时发生。颜色不能代替动作拆解。
- 对应关系建立后，可以弱化临时填色或高亮，将注意力交给下一步关系；仍承担后续推理依据的标记继续保留。

## 动作的数学含义

| 动作 | 必须保持或说明的关系 |
| --- | --- |
| 平移、旋转 | 尺寸和形状保持；使用整体变换，不用顶点插值压扁图形 |
| 分割、重组 | 子块身份可追踪；落定时无重叠且完整覆盖，才可声称拼合区域等价 |
| 对齐、叠合 | 明确比较对象；不能把叠合面积重复当作并集面积 |
| 参数变化 | 说明什么在变，所有依赖图形与数值从同一参数更新 |
| 镜头缩放 | 区分画面倍率与数学尺度；需要时显示刻度 |
| 图形转符号、合并项 | 项的来源仍可找到；等号成立，依据已有明确承接 |

面积拼图移动时，单块面积与面积之和可保持不变，空白或并集面积不一定不变。参数曲线允许改变形状，但保持面积的证明不能用任意形变冒充刚体运动。

## 衔接与时间

- 优先保留同一对象并改变布局，或保留图形并建立对应符号；扩大视野时说明新尺度。确实切换概念时可以干净切换，不强行变形。
- 跨场景记录共享对象的出口/入口位置、比例、标签和参数。全屏淡入淡出不承担核心推理；同一位置的两段可读文字不交叉叠放。
- 一次主要变化配一个注意焦点。教学移动通常平滑加减速，数据等速变化用线性推进；路径让来源与去向容易追踪。
- 简单移动约 0.8–1.6 秒、重组约 1.5–3 秒、结果观察约 1–2 秒可作调试起点，以实际阅读难度调整。无声字幕一次说一个关系，不靠无意义运动填满停顿。

## 视觉与实现

用户已有设计优先。无设计时可从背景 `#0B151C`、主文字 `#F3F5F7`、辅助文字 `#AAB6C2` 开始；绿 `#55DFBC`、红 `#F47D7D`、紫 `#B19CFF` 需有稳定角色，身份不单靠颜色。

在现有 `frame.md` 或视觉说明中定义一次语义配色表：含义、颜色、使用范围；图形与公式从同一映射取色，具体色值不写死为所有题目的变量规则。

- 同一变量在数学标注、条件和主公式中保持同色；相关区域可用同色系呼应来源，但仍以边长、面积符号说明不同量。
- 复合项逐变量保留颜色，例如 `ab` 中 a、b 分别沿用自己的颜色。区域填色可另表示面积类别，不能覆盖字母身份；填色宜减弱，确保字母可读。
- 运算符、括号及指数默认用中性白色；自然语言标题、说明不逐字染色。字幕整句统一白色，即使其中出现变量也不继承变量色，用户另有明确要求时覆盖。
- 用局部高亮和时序提示当前重点，不临时改换变量身份色；保持可见字母或形状线索，使不用颜色也能追踪对象。

字体也在同一视觉说明中按角色定义，避免每个场景重新选择：

| 角色 | 1920×1080 下的可覆盖起点 |
| --- | --- |
| 中文大标题 | 苹方 `PingFang SC`（本机可用时）优先；700 字重，步骤标题约 76–88 px，短开场标题可试 120–150 px |
| 数学公式与标注 | 匹配参考的数学字形；简洁无衬线风格可用 `Helvetica Neue`，显式定义正体/斜体与字重，不能把中文标题加粗规则套到全部公式 |
| 字幕 | 中文字体 400–500 字重，约 32–40 px，统一 `#F3F5F7` |

以上字号是布局起点，长标题优先精简或合理换行，不能挤压主图。数学标注约 40–56 px、关键线条 3–5 px、安全边距约 5%；以缩屏检查决定最终尺寸，小区域用外置引线，给字幕及含标注的运动范围留空间。

有字体参考时对照实际字形与粗细，核实渲染器实际命中的字体、字重及回退；不能只因 CSS 写了字体名就声称匹配。系统字体选择可能随机器变化，项目记录显式字体族与已验证字面，不把缺失字体静默替换后当作同款。没有原工程或字体来源时，结论写“视觉近似”，不承诺准确识别。不为换字体另建工具或复制系统字体文件。

遵循当前 `hyperframes-core` 合同，复用已有组件；共享对象通常放在持续存在的 SVG/场景容器中，步骤是同一时间线的状态。数学坐标与画布坐标分开，随机演示固定种子，资源在渲染前就绪。不在此复制框架 API，也不为简单需求增加通用布局引擎。

有参考视频时，只抽查关键运动开始、中间、结束及相邻转场，学习对象延续、注意转移和停顿的方法；不据成片猜测原软件或源码。
