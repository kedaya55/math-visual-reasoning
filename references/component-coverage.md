# 小学、初中主干知识的组件覆盖

本页按数学表征组织，不声称逐条覆盖某一版本教材。组件提供图形、数量关系、标注与可重复更新；题目的条件、证明步骤、来源交接和教学节奏仍由工程负责。

[统一交互预览](../assets/math/library-preview.html)展示本次新增的 10 类组件。原有直角三角形、圆、矩形、坐标轴继续使用原预览与接口。

| 表征 / 模块 | 可以支持的常见知识点 | 组件已经提供 | 题目仍需组织 |
| --- | --- | --- | --- |
| 数轴 `number-line.mjs` | 有理数、相反数、绝对值、大小比较、加减、区间、不等式解集 | 等比例刻度、小数步长、命名点、带方向的位移、开闭端点；识别空区间 | 运算规则的推导、多个区间的交并 |
| 等分格 `fraction-grid.mjs` | 分数意义、通分、分数加减、小数、百分数、比与比例、面积单位 | 同一整体、行列等分、选中数量、精确比例、来源组与可移动子块 | 相同整体的比较、分数乘除的具体覆盖或分组 |
| 一般多边形 `polygon.mjs` | 一般三角形、平行四边形、梯形、多边形周长与面积、全等与相似、轴对称 | 顶点与边标同步、指定底边的高及延长线、平移 / 旋转 / 反射 / 等比缩放 | 补形、剪拼、全等或相似的充分条件，不能用形似替代证明 |
| 角标 `angle.mjs` | 角度、直角、邻补角、对顶角、内角和、平行线中的角、圆心角 | 任意两射线的小角 / 优角 / 周角、角弧、正立标签、直角方框 | 平行、相等或互补关系的前提和逐步交接 |
| 圆与扇形等分 `sector-partition.mjs` | 圆面积、弧长、扇形面积、等分与极限直觉 | 等角分割、每块面积与弧长、来源组、独立位移 / 旋转及弧线标记 | 从有限块到极限的论证，重排目标与无重叠检验 |
| 函数图 `function-graph.mjs` | 一次 / 正比例、二次、反比例函数，图像与点，增减变化 | 复用坐标轴；三类函数、观察点及投影线、二次函数顶点数据、反比例断点 | 待定系数、交点求解、定义域说明与一般性质证明 |
| 代数块 `algebra-tiles.mjs` | 正负数、同类项、整式、平方展开、因式分解、方程两边的项 | 带身份的 ±1、±x、±x² 块，正负线型，系数汇总与代入计算 | 配对消去、两边同加同减等合法变换及公式排版；负块并非负几何面积 |
| 立体图 `solid.mjs` | 长方体 / 正方体、圆柱、圆锥的体积与表面积；球作扩展 | 固定投影线框、遮挡虚线、尺寸标注、真实参数的体积与表面积 | 展开图、截面、切拼或灌装推导；投影线长不能直接量作真实长度 |
| 统计图 `data-chart.mjs` | 条形图、折线图、扇形图、百分比、平均数、中位数 | 零基线、类别身份、非负数值、占比、均值与中位数 | 抽样解释、频数分布和加权统计；当前均值针对输入值列表 |
| 概率树 `probability-tree.mjs` | 列举、树状图、连续试验、放回 / 不放回事件 | 条件概率分支、路径乘积、末端概率，逐层和为 1 的校验 | 事件集合和“哪些末端属于同一事件”的说明 |
| 已有直角三角形、矩形、圆、坐标轴 | 勾股、面积、周长、半径、斜率、锐角三角比的直角三角形表征 | 已有尺寸 / 坐标模型和标注跟随 | 新命题的条件、数量关系和推导 |

## 覆盖含义与边界

- 已补齐数与运算、代数与函数、平面与立体几何、统计与概率的常用表征基础，不等于已经生成这些知识点的全部成片。
- 连续参数更新与结构性变化分开：移动、旋转和尺寸变化保留存续对象节点；改分母、增删项或改图表类别可能增删节点。分割必须由题目提前展示来源，再使用来源 ID 安排子块出现，不用瞬间调用 `update` 冒充完整分割动画。
- 有限数量和样例不能替代一般数学证明。模型检查、组件画面检查、接入视频后的检查和学生学习效果是四件不同的事。
- 尚无自动公式排版、碰撞避让、通用剪拼求解、尺规作图约束、立体展开 / 截面、任意函数绘图或全教材逐条教学验证。遇到这些题目时再补相应能力，不把当前组件标记为已经支持。
