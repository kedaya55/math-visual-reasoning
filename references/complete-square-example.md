# 完全平方公式：核心动画参考设计

本文件是制作参考设计，实际样片状态与问题以工程 QA 为准；不是效果验证报告。面积模型或图形转公式时按需读取。目标是解释“为什么展开式有两个 ab”，不强制其他知识点使用同样分镜。

## 数学目标与条件

观众已知矩形面积和乘法交换律。先讨论 a>0、b>0，面积模型的结论是 `(a+b)² = a² + ab + ab + b²`。利用 `ab+ab=2ab` 得到完全平方公式。

若完整视频要主张恒等式对所有实数成立，应补充 `(a+b)(a+b)=a(a+b)+b(a+b)` 的分配律依据；不能让普通面积模型单独承担负数情形的证明。

主画面建议 a=3、b=2，但标签保留 a、b，以一般尺寸论证。选不相等的长度，使两个平方与两块方向不同的矩形容易区分。

## 统一模型

使用向右为 x、向下为 y 的示意坐标；这里描述绘图坐标，不把它冒充函数坐标系。整体边长 `s=a+b`。

| 语义 ID | 区域 `(x, y, 宽, 高)` | 面积与角色 |
| --- | --- | --- |
| `whole-square` | `(0, 0, s, s)` | 外框与整体 `(a+b)²` |
| `area-a2` | `(0, 0, a, a)` | 左上 a²，绿 |
| `area-ab-top` | `(a, 0, b, a)` | 右上 ab，紫 |
| `area-ab-left` | `(0, a, a, b)` | 左下 ab，紫；独立标签保留身份 |
| `area-b2` | `(a, a, b, b)` | 右下 b²，红 |

整体外框是轮廓，不能在面积求和中再次当成第五块。分割时保持外框与四块边界一致，切线为 `x=a`、`y=a`。

本例可将 a 标为青绿 `#55DFBC`、b 标为珊瑚红 `#F47D7D`，分别呼应 a²、b² 区域；两块 ab 区域沿用弱紫色填充，内部 a、b 字母仍分别保持青绿、珊瑚红。主公式与数学边长使用同一映射，运算符、括号、指数用白色；字幕整句白色。颜色说明来源对应，不表示边长与面积是同一量。将这些值写入工程现有视觉说明，不为其它题目强制沿用本例映射。

## 约 28 秒的核心段

时间是无声初稿起点，实际按阅读和观察调整。六个步骤共用同一张图及同一组对象，不拆成六个独立页面。

| 时间 | 对象变化与注意焦点 | 数学依据、结论和衔接 |
| --- | --- | --- |
| 0–4 秒 | 显示整体正方形，边长括号标成 a+b；建立整体面积标签 | 先确认整体，后续外框保留 |
| 4–9 秒 | 顶边与左边标出 a、b 两段；两条切线依次画入，露出四块 | 切线从真实分界出发；四块共同覆盖原图 |
| 9–14 秒 | 先强调 a×a 的边与区域，显示 a²；再强调 b×b，显示 b² | 标签出现前先看见相关边长；四块都留在原位 |
| 14–20 秒 | 单独强调右上矩形的 a、b，再强调左下矩形的 a、b，各写 ab | 观众确认两块来源不同、面积相同；无需重画或拉伸矩形 |
| 20–25 秒 | 原图缩至预先规划位置或保持原位；按 a²、ab、ab、b² 顺序高亮区域，在公式行建立对应项 | 镜头/布局缩放不改变边长值；原图上的标签继续作为依据 |
| 25–28 秒 | 两个 ab 项用括号分组，转换为 2ab；图上两块同步轻度高亮，停留 | 最终显示 `(a+b)²=a²+2ab+b²`；两块矩形仍可见，解释“2”的来源 |

字幕可以依次为：“两条边都是 a+b”“沿着分界，分成四块”“这两块是 a² 和 b²”“还有两块，每块都是 ab”“四块加起来，就是整个正方形”。只在对应步骤显示，别堆在画面上。

需要移动图形腾出公式空间时，让整个图形及附属标签使用同一画面变换；固定数学模型。更简单的方案是从开始就预留公式行，避免额外镜头。

如果将两块矩形移出原图并旋转比较，应先在原位把 a、b 从分割边长交接到各自的物理边，再连同标注一起移动。左下矩形可将 a 绑定底边、b 绑定左边；顺时针旋转 90° 后，它们分别位于左侧和上方，文字保持正立。右上矩形可将 a 绑定右边、b 绑定顶边。比较终点应为两组外置标注留空间，必要时调整两矩形的左右排列与路径。

依据链是“原图分割长度 → 每块矩形的两条边 → 每块面积 ab → 两块相加 2ab”。建立面积 ab 后才可逐步减弱已承接的边长标注；不能在分离前擦掉边长、到落定后重新补上。实现见 [边长标注组件](edge-label.md)。

## 接入完整视频

用户请求完整教学视频时，可在前面用“边长相加，面积可以只把两个平方相加吗？”提出预测，在后面让学生指出 `a²+b²` 遗漏的区域。是否增加数值应用由目标与时长决定，不为凑时长再讲一套无关公式。

可选改变正参数 a、b，保持分割逻辑和标签关系；这帮助观察多种情况，不能替代上述一般面积论证。

## 该案例的检查点

- 区域宽高非负，四块无内部重叠，边界覆盖 `[0,s]×[0,s]`。
- 四块面积之和为 `a²+ab+ab+b²=(a+b)²`；选 a=3、b=2 时为 9+6+6+4=25。
- 对 a=2、b=3 及 a=b=2 再算一次，检查尺寸次序和对称特例；这些是模型检查，不是数学证明。
- 在切线绘制、布局移动、两个 ab 合并的中间时刻检查标签归属、重叠与可读性。
- 若使用移出与旋转，逐步核对上述依据链，确认标注在移动前已建立、途中未中断，且属于同一条物理边。
- 合并 ab 时不能让图中一块矩形消失，造成“只剩一块”的误解。
- 如果结尾出现“对所有实数成立”，确认代数依据确实出现在所请求的完整内容中。
