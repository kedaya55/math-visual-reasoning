# 随包数学组件

选择表征或接入图形时读取。所有路径相对本 skill，复制整个 skill 文件夹即可携带组件；无需原开发项目。

先查[覆盖表](component-coverage.md)，确定表征后查[新增组件接口](component-api.md)。外观可打开[离线统一预览](../assets/math/library-preview.html)；不要默认读取所有模块或完整预览源码。

组件位于 `assets/math/`。将需要的模块、依赖和 `math-style.css` 复制到新工程 `assets/`，工程使用自己的相对路径；不引用安装位置或原项目的绝对路径。

- 新增模块依赖 `svg-helpers.mjs`；多边形另依赖 `edge-label.mjs`。
- 函数图与坐标轴搭配，通常需 `coordinate-plane.mjs`。
- 原有直角三角形、矩形依赖 `edge-label.mjs`；圆形、坐标轴可独立使用。
- 原有组件接口可先读相应模块的导出及参数定义，或查看随包的三角形、圆、矩形、坐标轴离线预览。物理边标注详见[边长标注](edge-label.md)。

组件无运行时第三方依赖；HyperFrames 与动画运行库由制作工程准备。本机验收组合为 Node 24.18.0 / HyperFrames 0.8.30。组件模型测试需要 Node 22 或以上。字体与跨平台画面仍需实际检查。

组件提供几何与数值更新，不提供整题自动编排、公式排版、标注自动避让、通用剪拼或立体展开。不要把“支持一种表征”当作“已经证明一道题”。
