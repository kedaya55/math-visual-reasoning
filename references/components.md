# 随包数学组件

选择表征或接入图形时读取。所有路径相对本 skill；复制整个 skill 文件夹即可携带组件，无需原开发项目。

先查[小学、初中课程索引](curriculum-coverage.md)，按知识点定位模块。新增组件查[补充接口](expansion-api.md)，原有组件查[主干接口](component-api.md)。打开[新增 39 类离线预览](../assets/math/expansion-preview.html)或[原有统一预览](../assets/math/library-preview.html)。不要默认读取所有模块或预览源码。

## 复用层级与自由度

基础形体、默认投影与线条/填色先沿用对应组件和已确认案例；自由设计主要用于本题的动作、路径、节奏、强调和教学角色。既有颜色仍按数学含义使用，不为增加新鲜感重画已有形体或另换整套视觉。

1. **先查完整组件**：按题目定位对应模块，只读相关接口与默认预览，确认模型、绘制和所需动作能否满足需求。完整组件适用时，直接调用，在同一模型上叠加本题标记与运动。
2. **有缺口再降到模型层**：明确缺的是面定位、填面、遮挡、可变视角还是其他具体能力；先保留可用的几何模型与投影，只补本题必需的显示或动作。组件默认行为妨碍教学时可以调整，不为满足“复用”硬接不合适的组件，也不为单题扩建通用框架。
3. **底层重建需要具体依据**：完整组件与模型都不适用时，可用空间场景等底层能力实现。在已有分镜或工程说明中简记采用的模块、复用层级与具体缺口，不另建审批流程。仅引用 `cameraModel`、坐标转换或 SVG 工具，不等于复用了完整形体组件；交付说明须如实区分。
4. **调整要服务于教学**：修改已有形体的投影、比例或视觉时，说明它帮助看清哪个关系，并核对几何含义、基础形体辨认和系列视觉一致性。新增角色与运动不能另建一套与形体不一致的坐标。空间形体另按[空间几何约定](spatial-geometry.md)验收。

接口边界示例：`solid.mjs` 的长方体提供固定斜投影、线框、尺寸标注及 `project`，不直接提供面填色、通用遮挡或跨面运动。固定视角下可先评估在同一模型上补充；确需旋转或遮挡时，评估适合的空间组件或 `spaceSceneModel`，不能假定调用一个投影函数就已完成组件复用。

组件位于 `assets/math/`。复制所需模块及递归相对依赖和 `math-style.css` 到工程；可调用：

```sh
node <本skill目录>/scripts/copy-math-components.mjs <工程目录>/assets cone-surface.mjs
```

脚本自动带上本模块依赖，不覆盖已有不同文件；可一次传入多个模块名。工程仅引用自己的相对路径，不引用 skill 安装位置。新增模块通常依赖 `diagram.mjs`，而三维组件还依赖 `space-geometry.mjs`；不要按旧规则仅复制 `svg-helpers.mjs`。按需查看对应模块的导出和输入校验。

- 空间展开、贴面路线或截面，先读[空间几何约定](spatial-geometry.md)。
- 随刚体移动的物理边标，读[边长标注](edge-label.md)。
- 查看[补充检查记录](expansion-qa.md)，区分模型检查、画面检查和视频验收。

无运行时第三方依赖；HyperFrames 与动画库由视频工程准备。组件模型验收环境为 Node 24.18.0；字体和跨平台画面仍需检查。

组件提供几何和数值状态，不自动解题、证明、排整段动画或避让标注。结构化公式不等于任意 TeX 排版；指定展开和一次凸剪分不等于通用展开/剪拼求解。
