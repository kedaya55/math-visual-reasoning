# 面积重排：让动作给出等面积证据

设计面积拼图、对应扣除或区域到公式的衔接时按需读取。此例提炼勾股定理核心试片的有效做法，供类似推理迁移；不规定所有视频的证明方法、配色、时长或固定镜头数。

## 先明确本段已有依据

四块全等直角三角形的直角边为 a、b；中央已经证明是边长 c 的正方形。本段解释重排后的剩余面积为何等于 c²。若前段未建立中央正方形，就先补上该论证，不能靠染色和 c² 标签跳过。

## 动作如何产生证据

| 已有对象与动作 | 观众能看出的关系 | 设计理由与承接 |
| --- | --- | --- |
| 当前完整拼法连续移出一个等大参照，工作图保留 | 两种排列从同一状态开始，外框大小相同 | 明确副本是参照；给两图相等的尺度和可读空间，接着在工作图内操作 |
| 按依赖顺序逐块平移三角形，形状、填色及身份标记延续 | 移动后仍是原来那四块 | 已标出的 a、b 跟随物理边；移动中不声称空白面积不变，完整落定后再比较 |
| 沿落定后的边指示两块空白，边长对应清楚后出现 a²、b² | 两块剩余区域的面积各有边长依据 | 标记从随图块移动的边承接；不等终态才凭空贴上面积名 |
| 两图中对应的三角形逐对强调并淡出 | 同样大的外框扣除了同样四块，所余总面积相等 | 配对节奏让“同样相减”成为可见证据；淡出表示扣除，不表示三角形缩小或变形 |
| 区域中的 c²、a²、b² 连续移到等式位置，区域本身保留 | 等式的每一项来自刚才比较的面积 | 关系已经建立后接入等号和加号，留时间同时查看图形与 c²=a²+b² |

## 这类片段的视觉选择

图块填色应让来源与去向容易辨认，辅以编号或形状，不能只靠颜色；仍需使用的物理边标跟随对象。比较阶段收起已完成作用的讲解文字，将空间交给两幅同尺度图形。面积区域、被扣除的图块和外框有不同强调层次，让视线随操作转移。

参照分出时要处理副本重叠：可使用遮挡关系、适当错开路径或标记交接，避免两套符号长期叠在一起。检查正常速度下的实际接续，不将“无黑闪”直接等同于“清楚”。

## 如何迁移

可迁移的是对象延续、统一比较基准、对应操作和符号来源。分数题先统一整体；等式变形先保证两边操作合法；函数题通过共享参数体现联动。根据本题选择动作，不能把任何等式都演成图块淡出，也不能用几个数值状态代替一般证明。

验收时保留必要边长和先修条件，遮住解释句，确认仍能追踪同一图块、看见对应扣除并找到公式项来源。该案例来自一段已制作、检查且获得用户正向反馈的试片；跨题目生成质量与学习效果仍需后续验证。
