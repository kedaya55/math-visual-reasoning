# 数学推理设计

在选定主题后读取。这里决定解释什么、为什么成立；运动实现见 `continuous-animation.md`。

## 从理解障碍选择表征

将目标写成学生能够解释的一句话，例如“展开平方时为什么还有两块面积”，而不是“掌握完全平方公式”。只选择当前视频能支撑的一个核心目标。

| 困难 | 候选表征 | 需要守住的条件 |
| --- | --- | --- |
| 部分与整体、分配律 | 面积分割、矩形阵列 | 单位一致，分割无漏算和重复计数 |
| 分数及通分 | 等长条、同一数轴、等面积整体 | 比较前固定整体；重新等分不改变原来的量 |
| 等价关系 | 等式两边同步操作、数量天平 | 同步操作有定义；除数不为零；适用范围明确 |
| 全等、面积证明 | 刚体移动、分割重组 | 不缩放、不拉伸；区分移动中与完整拼合状态 |
| 函数与变化率 | 坐标系、移动点、差量线段 | 标签与函数值同源；解释坐标轴尺度 |
| 极限、导数 | 参数靠近、割线变化、局部放大 | 有限步演示是直觉；极限存在性不能由动画保证 |
| 概率 | 样本空间、树图、频数变化 | 等可能性有依据；一次模拟频数不是理论概率 |
| 空间关系 | 空间图形加二维截面或投影 | 投影变形不代表真实长度或角度变化 |

这些是选择提示，不是必用模板。无法用候选表征解释目标时，换表征或缩小命题，而不是加入更多文字掩盖断点。

## 每一步都要有理由

编写一条最短的充分论证链：条件 → 合法操作 → 可观察关系 → 结论。检查是否有学生必须“相信作者”的跳步。

例如勾股拼图中，中央四边形是正方形需要两个事实：边均为斜边 c；相邻三角形的锐角互余，从而中央角为直角。只染成紫色并写 c² 不足以解释这一步。

### 让动作承担推理

对每个关键关系，先回答“观众能从哪个变化看出它”，再写字幕。分割显露组成，刚体移动显露对应，叠合显露相等，同步操作显露等价，参数联动显露依赖；选择本题有解释力的动作，不为增加运动而全部使用。文字或公式淡入、描边闪烁、镜头移动可以引导注意，但单独使用不等于展示关系的形成。

例如解释中央直角，可把同一直角三角形的两个锐角以保角的副本移到一起，显出互余，再对应回中央顶点的平角缺口；用角弧及直角标记承接关系，最后收束为角度等式。副本须说明来自哪里，不能用任意角度形变把待证角“变成”直角。这是动作设计示例，不要求所有题目复制该构造。

必要条件、先修知识及无法仅靠画面证明的论证仍可用精炼文字说明。动画不必承包所有抽象证明，但能视觉化的关键步骤不能仅以“图已画好＋文字宣布”代替；也不按字数或运动时长比例机械判定质量。

公式允许在开头作为问题或已知条件出现；作为结论出现时，要能对应回刚刚建立的关系。不要机械规定所有符号都必须最后出现。

## 学生已知与呈现顺序

在已有分镜中，为关键步骤记录“当前已知 → 操作及理由 → 新得到的关系”。当前已知包括本片声明的先修知识、题目条件和前面已建立的关系，不默认学生已经知道待求答案。已有依据表负责对象对应，这条记录负责推理先后，不另建一套文档。

- 检查的不只是文字：精确路线、特殊位置、角标、颜色分组和运动结果，也可能提前传达待证性质。尚未证明的对象或性质若作为猜想、候选方案或结果预告出现，应自然说明其身份；后续仍须给出独立依据，不能因画出来或试过几次就视为成立。
- 辅助线、分割和坐标选择可以由讲解者主动提出。说明它有助于建立什么关系即可，不要求学生自行发明，也不为每次常规作图添加说明。能按已知条件执行的构造可先画；该构造是否最短、等长或垂直等性质，需要已有知识、构造定义或后续论证支持。
- 制作顺序不等于教学顺序。可先求解、计算最终位置和预建完整模型，以保证几何准确；通过时间状态安排何时向学生显示。对象追踪从它合理进入讲解时开始，不要求把最终解从开头一路保留。
- 定理讲解可先陈述待解释的命题；探究可先提出猜想；复习、答案演示或用户明确要求的结论预览可先展示结果。此时改变讲解目标并明确身份，不强制套用“未知问题—发现答案”的叙事；若仍声称解释了为什么，就不能省略依据。

例如圆锥最短路：可先用展开图计算曲面路线，但求解讲解应先说明展开保长、将问题转到平面，再用线段最短确定路线，最后映回圆锥。开头展示候选路线并非禁止；不能把预先算出的精确最短路线默认为已知，再仅计算它的长度。

## 直觉与证明的边界

- 一个 3、4、5 三角形只能说明一个例子。保持直角并连续改变边长也只是展示多种情况。
- 面积模型中的 a、b 通常先取正数。若最终主张完全平方公式对所有实数成立，需要补上代数依据；不能把负数画成普通的负长度。
- 函数动画中的几个样本点不能证明整条曲线的性质。图形应由函数定义产生，而非用看起来合适的曲线拟合后宣称精确。
- 割线极限先保持两点不同，不在 h=0 时计算差商。画面可展示趋近；精确结论需说明导数存在的条件或给出该例的解析依据。
- 直观解释可以是完整交付，但要自然标明它解释到哪一步，不能把“看起来如此”写成“一定如此”。

## 根据对象选择数值

数值用于让关系容易看见，不代替一般变量。避免只选对称或退化样例，使错误碰巧成立。

例如完全平方公式的主要画面采用 a≠b，这样 a²、b²、两个方向不同的 ab 矩形可区分；等值情形可作为后续检查。

## 迁移题

完整教学视频可在结尾给一个与目标直接相关的预测或解释问题，留出停顿再展示理由。用户只要核心片段时不强加练习。

- 完全平方公式：只取 a²+b²，漏了哪两块？为什么每块都是 ab？
- 勾股定理：保持四块三角形全等，换一种完整排列后，怎样判断剩余总面积？
- 斜率：水平变化翻倍时，竖直变化怎样变，比例为什么保持不变？

记录预期解释与常见错误，以检查成片是否提供了必要依据。不要把练习答对直接等同于长期掌握。
