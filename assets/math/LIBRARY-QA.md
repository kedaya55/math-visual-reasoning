## 本次发现并处理

- 增删代数块、切换统计图类型后，恢复的图层顺序不一致：固定组件内部层与项的排列顺序。
- 提高细分度时旧索引可能转指另一来源：子块 ID 包含来源与细分层，来源组 ID 单独保留。
- 半开区间两端相等时不应画出一个包含点：模型识别为空区间；零位移不显示有向箭头。
- 外部高叠加旋转时顶点文字越界：扩大该预览的固定观察范围，并补查联合参数。
- 直角方框与数值相碰：方框使用较小标记尺寸，数值仍放在角平分线方向。
- 圆柱 / 圆锥 / 球的半径线与半径标签统一为绿色；扇形来源组同时显示字母标记。
